# Customer Sales Analysis Project 📊

## Project Overview
This project focuses on cleaning, transforming, and visualizing retail sales data to extract meaningful insights about customer behavior and sales trends. The workflow covers the entire data pipeline: from initial processing in Python to advanced SQL transformations and final visualization in Power BI.

## Tools Used
- **Python (Pandas):** For initial data exploration, handling missing values, and data cleaning.
- **SQL Server:** For data storage, complex transformations, and feature engineering (Creating Age Groups).
- **Power BI:** For building an interactive and professional dashboard to communicate insights.

## Key Insights
- **Sales by Category:** Identified the top-selling product categories (Clothing, Electronics, etc.).
- **Demographics:** Analyzed sales distribution across different Age Groups (Youth, Adults, Seniors).
- **Customer Satisfaction:** Monitored average ratings across different segments to identify areas for improvement.
- **Trends:** Visualized sales performance over time to detect seasonal patterns.

## Files in this Repository
- `project.ipynb`: Python script for initial data processing using Pandas.
- `SQLQuery1.sql`: SQL scripts for data transformation and grouping.
- `final project_Dashbard.pbix`: The Power BI file for interactive visualization.
- `Dashbard.png`: A high-quality screenshot of the final dashboard.
